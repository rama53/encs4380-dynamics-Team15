Module 2: First-order frequency response

A first-order sensor driven by a sine wave. G(jω) = 1/(jωτ + 1), M = 1/√(1 + (ωτ)²), φ = −arctan(ωτ). In steady state the output is a sine at the same frequency, smaller and late.

Bigger τ means a slower sensor and a lower cutoff.
How fast the input sine oscillates.

Input and steady-state output

The output amplitude is M times the input amplitude, and the output is shifted in time by the phase lag.

Input sin(ωt)Output M·sin(ωt + φ)

Bode magnitude

20·log₁₀(M) against ω. The dashed line marks the cutoff ω = 1/τ, where the magnitude is −3 dB.

Bode phase

The phase falls toward −90° as ω grows. At the cutoff it is exactly −45°. The dot shows your current ω.
