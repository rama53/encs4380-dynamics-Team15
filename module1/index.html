Module 1: First-order time response

A thermometer-like sensor with gain K and time constant τ. τẏ + y = Kx, G(s) = K/(τs + 1). The input is a unit step (A = 1) or a unit ramp (slope a = 1).

Bigger τ means a slower sensor.
K scales the output.

Step response y(t) = KA(1 − e−t/τ)

Step error fraction on a log axis

This plot always uses the step response, in both modes. It shows ln(1 − y/KA), computed point by point from the response curve. The points fall on a straight line whose slope is −1/τ, so you can measure τ from any curve.
